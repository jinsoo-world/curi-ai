## 2. /home 주소 넣기(HomeMake)가 부르는 것

1. 칩 제목: `GET /api/home/link-title?url=`
2. 「내 AI 만들기」: 서버 호출 없음. 브라우저에 보관(`saveHomeDraft`, 열쇠 `curi-home-draft`, 하루) 후 로그인한 사람은 `/os?new=1`, 손님은 `/login?next=/os?new=1`
3. `/os` 에서 `NewBotSheet` 의 LinkDraftTab 이 보관분을 읽어
   - `POST /api/os/twin-draft` (로그인 필요, 401) = 읽고 초안(이름·소개·인사·프롬프트·첫 질문·예시 문답)
   - 사람이 고친 뒤 `POST /api/os/twin-draft/create` = 봇 저장, 인사말에 「무엇을 읽었는지」 한 줄을 붙여 greeting_message 로
4. 만들어지면 명단 새로 읽고 `/os/chat/{mentorId}` 로. 봇 인사말이 첫 말풍선

## 3. 이번에 바꾸는 흐름

- 새 화면 `/os/make` (뼈대 안 본문) = 주소 넣기 칸. 문구는 HOME_COPY 그대로
- 로그인한 사람: 「내 AI 만들기」 → 같은 두 API(twin-draft → twin-draft/create)를 차례로 불러 고치기 단계 없이 바로 봇 저장 → 명단에 생기고 대화방이 열리며 봇이 먼저 말한다
- 손님: 같은 보관(`saveHomeDraft`) → 로그인(카카오 먼저) → `/os/make` 로 돌아와 이어 만든다
- 초안이 저장 기준에 못 미치면(프롬프트 20자 미만 등) 옛 고치기 창(LinkDraftTab)으로 넘긴다
- 「＋ 개인봇」 → `/os/make`. 옛 만들기 창은 `/os?new=1` 과 /os/make 아래 「일 골라 만들기」로 남는다
- `/os`: 손님은 `/os/welcome` 대신 `/os/make`. 보관된 주소가 있으면 `/os/make`
