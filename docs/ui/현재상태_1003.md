## 3. 고치는 순서 (이번 PR)

1. 기초: 전역 토큰(`@theme`)과 옛 한글 변수 값을 큐리어스 값으로. 공통 부품 `src/components/ds/`.
2. /home → /os 대화 → 봇 마켓·봇 소개 → 요금제. 토큰을 쓰는 화면은 토큰만 바꿔도 같이 바뀐다.
3. 화면 파일 안 손으로 적은 색은 같은 역할의 큐리어스 토큰으로 기계적으로 바꾼다(모양만, 동작 그대로).
