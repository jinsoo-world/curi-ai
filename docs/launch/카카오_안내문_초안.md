# 카카오 안내문 초안 (리더용 3종)

작성 2026-09-23. 큐리어스 리더(강사·작가·크리에이터)에게 카카오로 보낼 3줄 안내 3종.
**발송하지 않는다.** 대표 승인 게이트(대표 번호 테스트 → 대표 승인 → 본발송)를 지난 뒤에만 나간다.
규칙: 회원 실명·플랫폼 내부 숫자 없음. 줄표(—)·중간점 나열 없음. 담백한 평문, 줄바꿈으로만 나눈다.
링크는 손으로 조립하지 않고 `utm_발행.py` 로 만든 것을 `[링크]` 자리에 넣는다.

---

## A. 봇 팀 소개

```
리더님, 큐리AI에 이름 있는 AI 팀원이 생겼어요.
답장봇, 글감봇, 비서실장처럼 봇 하나가 일 하나를 맡아서 리더님 자료로 답하고 초안을 만듭니다.
첫 봇은 칩 세 번만 누르면 만들어져요. [링크]
```

## B. 내 자료로 답하는 봇

```
강의 자료나 써 둔 글을 올려 두면, 봇이 그 안에서만 답합니다.
자료에 없는 건 지어내지 않고 "제가 가진 자료에는 없어요"라고 말해요.
팬 질문 답장 초안부터 한번 시켜 보세요. [링크]
```

## C. 승인 뒤에만 보내요

```
봇이 정리하고 요약하고 초안 쓰는 건 알아서 하지만, 밖으로 보내는 건 다릅니다.
메시지 보내기, 글 올리기, 돈이 움직이는 일은 리더님이 허용을 누르기 전엔 한 글자도 나가지 않아요.
허용한 기록은 전부 남아서 나중에 다시 볼 수 있습니다. [링크]
```
