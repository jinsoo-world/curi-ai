# 봇 답에서 **굵게** 줄이기

대표 피드백: 봇 답이 `**굵게**` 마크다운으로 가득하면 AI처럼 보인다.

## 접근 (둘 다)

1. **프롬프트** (`domains/os/response-settings.ts` `applyResponseSettingsToPrompt`)
   - 답변 설정 블록에 「**굵게** 와 # 제목 쓰지 마라」 한 줄을 항상 얹는다.
2. **렌더** (`components/os/BotMarkdown.tsx` + `domains/chat/markdown.ts` `stripMdBoldMarkers`)
   - 남은 `**...**` 마커는 평문으로 푼다.
   - `strong`/`b` 태그는 굵게 그리지 않는다.
   - 코드 울타리(```)와 인라인 코드(`) 안은 그대로 둔다.

목록(-)과 링크는 그대로 살린다.
