# 자료 동기화 후순위 — 옵시디언, 그라놀라

작성 2026-10-01. 갈래 G(구글 드라이브, 노션 동기화)를 만들면서 같이 검토했지만 이번엔 안 만든 것.
방법만 적어 둔다. 실제 구현은 나중에.

## 옵시디언(Obsidian)

- 옵시디언은 **서버 API 가 없다.** 문서가 그 사람 컴퓨터의 로컬 폴더(vault)에 그냥 마크다운 파일로 있다.
  그래서 「사용자 본인 계정으로 OAuth 붙이기」 같은 길이 아예 없다.
- 현실적인 두 가지 방법
  1. **로컬 플러그인 방식**: 옵시디언 안에 우리 플러그인을 하나 만들어(커뮤니티 플러그인), 그 플러그인이
     vault 안 파일을 우리 서버로 올린다(REST API 호출). 사용자가 옵시디언에 플러그인을 설치해야 한다.
  2. **동기화 폴더 방식**: 옵시디언 vault 를 iCloud Drive, 구글 드라이브 같은 곳에 두는 사람이 많다.
     그 경우엔 이미 만든 **드라이브 동기화(google_drive)** 로 그 폴더를 고르면 사실상 옵시디언 자료도
     들어온다. 추가 개발 없이 됨. 대표에게 먼저 이 방법을 안내하면 된다.
- 결론: 새 커넥터 만들기 전에, 먼저 "vault 를 드라이브에 두셨나요?" 부터 물어보는 게 제일 싸다.

## 그라놀라(Granola)

- 그라놀라는 회의 녹음 노트 앱. 공개 REST API 문서가 없다(2026-10 기준). 데스크톱 앱이 로컬 캐시에
  노트를 저장하고, 「Notion 으로 내보내기」 연동은 있다.
- 현실적인 두 가지 방법
  1. **노션 경유**: 그라놀라 설정에서 "노션으로 자동 내보내기"를 켜게 안내하면, 이미 만든 **노션 동기화**가
     그 페이지를 그대로 가져온다. 추가 개발 없음. 제일 빠른 길.
  2. **비공식 API**: 커뮤니티에서 그라놀라 로컬 캐시 파일(`~/Library/Application Support/Granola/`)을
     읽어 내는 방법이 알려져 있지만, 공식 지원이 아니라 앱 업데이트로 깨지기 쉽다. 권장 안 함.
- 결론: 그라놀라 전용 커넥터를 새로 만들지 말고, 노션 내보내기 설정을 먼저 안내한다.
