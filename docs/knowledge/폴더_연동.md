# 내 폴더 연동 (봇에 자료 넣기 → 「내 폴더」 탭)

대표 지시(2026-09-23): 「내 폴더 연동하는 기능도 추가해. 클로드코드처럼. 그 폴더 내의 파일들을 자동으로 탐색해서 긁어오는 게 필요해.」

## 무엇을 하나
1. 「폴더 고르기」를 누르면 내 컴퓨터 폴더 하나를 고른다.
2. 하위 폴더까지 훑어 문서만 목록으로 보여 준다(이름, 크기, 고친 날, 체크). 기본은 전부 체크.
3. 「고른 파일 넣기」를 누르면 「파일」 탭과 같은 길(올릴 주소 받기 → 저장소에 올리기 → 글 뽑기)로 한 개씩 올린다. 진행은 「12개 중 5번째…」로 보이고, 실패한 파일만 남겨 다시 누를 수 있다.
4. 「다시 훑기」를 누르면 지난번에 올린 뒤 새로 생겼거나 고친 파일만 골라 보여 준다.
5. 「열 때마다 훑기」를 켜 두면 자료 넣기 시트를 열 때 저절로 훑는다(권한이 살아 있을 때).

## 어디까지 되나 (브라우저별)
| 브라우저 | 폴더 고르기 | 다시 훑기(새 파일만) | 열 때마다 훑기 |
|---|---|---|---|
| 크롬, 엣지, 웨일 (컴퓨터) | 된다 | 된다 | 된다 |
| 설치형 앱(PWA, 크롬 계열로 설치) | 된다 | 된다 | 된다 |
| 사파리(맥, 아이폰), 파이어폭스 | 된다(한 번에 올리기) | 안 된다 | 안 된다 |
| 안드로이드 크롬 | 폴더 고르기 창이 없어 한 번에 올리기로 떨어진다 | 안 된다 | 안 된다 |

브라우저는 뒤에서 폴더를 계속 지켜볼 수 없다. 그래서 「열 때마다 훑기」까지가 한계다. 폴더에 파일이 생기면 알아서 올라가는 진짜 자동 감시는 설치형 데스크톱 앱(일렉트론, 타우리 같은 것)에서만 가능하다.

## 규칙
- 대상 파일: md, txt, pdf, docx, hwp, hwpx, pptx, xlsx, csv. 이미지, 영상, 코드, 숨김 파일(.으로 시작), 임시 파일(~$)은 뺀다. html 은 서버가 아직 글자를 못 뽑아 뺐다(서버 목록 `올릴수있는파일` 에 들어오면 자동으로 살아난다).
- 들어가지 않는 폴더: 숨김 폴더, node_modules, .git, dist, build, __pycache__.
- 상한: 파일 하나 10MB(서버 업로드 창구와 같은 값. 지시는 20MB 였지만 서버가 10MB 에서 막으므로 맞췄다), 한 번에 200개(넘으면 최근에 고친 것부터 보여 주고 나머지는 안내). 깊이 8단계, 읽기는 600개에서 멈춘다.
- 개인정보: 폴더 안 파일 이름은 서버에 먼저 보내지 않는다. 체크한 파일만 올라간다. 화면 문구 「선택한 파일만 봇에게 올라가요. 폴더 목록은 이 기기에만 남아요」.
- 서버 새 창구 없음. 기존 `/api/os/knowledge/upload-url` 과 `/api/creator/knowledge/process` 만 쓴다.

## 이 기기에 남는 것
| 무엇 | 어디 | 열쇠 |
|---|---|---|
| 폴더 손잡이(핸들) | IndexedDB `curi_os_folder` / `handles` | 봇 아이디 |
| 올린 파일 지문(경로, 크기, 고친 시각) | localStorage | `curi_os_folder_seen:<봇 아이디>` |
| 열 때마다 훑기 토글 | localStorage | `curi_os_folder_auto:<봇 아이디>` |
| 폴더 이름(보여 주기용) | localStorage | `curi_os_folder_name:<봇 아이디>` |

같은 경로 파일을 고쳐 다시 올리면 옛 지문은 지우고 새 지문으로 바꾼다(목록이 계속 자라지 않게).

## 파일
- 화면: `src/components/os/FolderSync.tsx` (탭 본문), `src/components/os/AddKnowledgeSheet.tsx` (「내 폴더」 탭 추가)
- 셈: `src/domains/os/folder.ts` (확장자 필터, 상한, 지문, 폴더 훑기, 기억 저장), 시험 `src/domains/os/__tests__/folder.test.ts`

## 아직 안 되는 것
- 진짜 자동 감시(폴더에 파일이 생기면 저절로 올라가기) = 설치형 데스크톱 앱에서.
- 폴더에서 지운 파일을 봇에서도 지우기 = 안 한다(사람이 자료 목록에서 지운다).
- 봇이 이미 갖고 있는 자료와 폴더 파일을 서버 기준으로 맞추기 = 안 한다(지문은 이 기기에만 있으니 다른 컴퓨터에서 열면 전부 새 파일로 보인다).
