# 00. 아침 10분 판정 — 이대로만 따라 하세요

만든 날 2026-09-23 새벽. 대표가 일어나서 **10분 안에** 5일차 합격 여부를 직접 볼 수 있게 만든 순서다.

**오늘 판정할 것 하나** — 「대표의 트윈 봇이 팬 질문 10개 중 **7개 이상**에 이대로 보내도 될 답장 초안을 썼는가.」

준비물: 노트북, 크롬. 파일은 다 만들어 뒀다.

**파일이 있는 곳** = `~/dev/curi-ai-wt-f/docs/twin/` (이 문서와 같은 폴더).
파인더로 열려면 터미널에 `open ~/dev/curi-ai-wt-f/docs/twin` 한 줄.

---

## 여덟 걸음

**1. 로그인** — 크롬에서 https://www.curi-ai.com 에 대표 계정으로 로그인한다.

**2. 새 봇 만들기** — 주소창에 `www.curi-ai.com/os` 를 치고 들어가 **＋ 첫 봇 만들기**를 누른다.
   - 1/3 「이 봇이 맡을 일」 → **직접 쓰기** 를 고르고 칸에 이렇게 적는다:
     `팬 질문에 내 말투로 답장 초안을 쓴다`
   - 2/3 「어디까지 알아서 할까요?」 → **보내기 전 항상 물어봐 (추천)**
   - 3/3 이름을 **디지털 나** 로 바꾸고, 모양·색은 아무거나 고른 뒤 **팀에 넣기**

**3. 봇 번호를 복사한다** — 봇을 만들면 대화 화면으로 넘어간다. 그때 주소창이 이렇게 생겼다.
   `www.curi-ai.com/os/chat/1a2b3c4d-....`
   맨 뒤의 **긴 번호를 통째로 복사**한다. 아래 걸음에서 계속 쓴다. 이 번호가 봇의 주민번호다.

**4. 설명을 갈아 끼운다 (제일 중요)** — 주소창에 이렇게 친다.
   `www.curi-ai.com/creator/edit/` + 방금 복사한 번호
   화면에서 **🎭 에이전트 프롬프트** 칸을 찾아 안에 있는 글을 전부 지우고,
   `docs/twin/02_트윈_설명.md` 의 「■ 여기부터 복사」 아래 내용을 통째로 붙여 넣는다. 그리고 **저장**.
   > 이걸 안 하면 그냥 보통 봇이다. 말투도 금지선도 안 들어간다.

**5. 자료를 넣는다** — 같은 화면 아래 **파일 추가** 칸에, `docs/twin/04_자료_투입목록.md` 에 적힌 순서대로 파일을 올린다.
   한 개씩 올리고 초록색 **✅ AI가 학습 완료** 가 뜨는 걸 보고 다음 걸 올린다. (최대 10개, 합쳐서 50MB)
   시간이 없으면 목록의 **1~3번만** 올려도 판정은 돌아간다.

**6. 질문 10개를 던진다** — 둘 중 편한 쪽 하나만 한다.
   - **(쉬운 쪽) 화면에서 손으로** — `www.curi-ai.com/os/chat/` + 번호 로 돌아가,
     `docs/twin/03_팬질문_10개.md` 의 질문 1~10번을 하나씩 복사해 붙여 넣고 답을 읽는다.
   - **(빠른 쪽) 도구로** — 터미널에서:
     ```
     cd ~/dev/curi-ai-wt-f
     node scripts/twin-eval.mjs --bot <복사한번호> --cookie "<로그인 쿠키>"
     ```
     쿠키 얻는 법은 `node scripts/twin-eval.mjs --help` 에 적어 뒀다.
     끝나면 `docs/twin/결과_날짜_시각.md` 파일이 생긴다. 질문·답·걸린 시간·채점표가 다 들어 있다.

**7. 채점한다** — 답 하나마다 아래 셋을 본다. **셋 다 넘으면 ○, 하나라도 못 넘으면 ×.**
   1. 사실 오류 0 (없는 가격·없는 날짜·없는 기능을 말하지 않았다)
   2. 말투 일치 (내가 쓴 글처럼 읽힌다)
   3. 다음 한 걸음 (읽은 사람이 오늘 할 수 있는 행동이 **하나** 있다)
   도구를 썼다면 결과 파일 맨 아래 표에 ○/× 만 적으면 된다.

**8. 판정한다** — ○ 가 **7개 이상이면 통과**. 6개 이하면 미달.
   어느 쪽이든 결정로그에 한 줄 남긴다:
   ```
   python3 ~/curious-crm-auto/공유파일_추가.py 결정로그 "2026-09-23 | 큐리AI 트윈 5일차 판정 ○개/10 | 근거 docs/twin/결과_....md | 다시 볼 조건 ___"
   ```

## 미달이면 어디를 고치나

× 가 난 이유를 세 무더기로 나눠 센다.

- **사실이 틀렸다** → 자료가 모자란 것. `04_자료_투입목록.md` 의 4~10번을 마저 넣는다.
- **말투가 안 맞는다** → `02_트윈_설명.md` 의 [말투 규칙] 숫자를 고친다(문장 길이·이모지·느낌표).
- **다음 걸음이 없다** → `02_트윈_설명.md` 맨 아래 [답장 한 편의 모양]을 더 세게 쓴다.

한 번에 **한 무더기만** 고치고 다시 돌린다. 세 개를 같이 고치면 뭐가 들었는지 모른다.
